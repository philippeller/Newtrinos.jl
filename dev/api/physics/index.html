Physics API

Oscillations

The oscillation module is accessed via Newtrinos.osc. Use Newtrinos.osc.configure to create an Newtrinos.osc.Osc physics module that can be passed to any experiment.

Configuration

Newtrinos.osc.OscillationConfig — Type
OscillationConfig{F, I, P, S, E}

Master configuration for the neutrino oscillation probability engine.

Each type parameter selects a different physical model via multiple dispatch. Construct with keyword arguments and pass to configure to obtain a ready-to-use Osc physics module.

Fields

  • flavour::F = ThreeFlavour(): neutrino mass/flavour model (FlavourModel).
  • interaction::I = Vacuum(): matter interaction model (InteractionModel).
  • propagation::P = Basic(): propagation mechanism (PropagationModel).
  • states::S = All(): eigenstate selection strategy (StateSelector).
  • eigen_method::E = DefaultEigen(): eigendecomposition algorithm (EigenMethod).

Examples

# Standard 3-flavour vacuum oscillations (all defaults)
cfg = OscillationConfig()

# Inverted ordering with MSW matter effects
cfg = OscillationConfig(flavour=ThreeFlavour(ordering=:IO), interaction=SI())

# ADD model with decoherence and Barger eigensolver
cfg = OscillationConfig(
    flavour=ADD(N_KK=3),
    interaction=SI(),
    propagation=Decoherent(σₑ=0.05),
    eigen_method=BargerEigen()
)
source
Newtrinos.osc.Osc — Type
Osc <: Newtrinos.Physics

Configured oscillation physics module, returned by configure.

This struct satisfies the Newtrinos.Physics interface and can be passed into any experiment's configure(physics=...) method.

Fields

  • cfg::OscillationConfig: the full configuration used to build this module.
  • params::NamedTuple: default oscillation parameter values (e.g. θ₁₂, Δm²₃₁, …).
  • priors::NamedTuple: prior distributions for each parameter.
  • matrices::Function: closure matrices(params) -> (U, h) returning mixing matrix and mass-squared eigenvalues.
  • osc_prob::Function: closure computing oscillation probabilities. See get_osc_prob for the two call signatures.
source
Newtrinos.osc.configure — Function
configure(cfg::OscillationConfig=OscillationConfig()) -> Osc

Create a fully configured oscillation physics module from the given configuration.

Assembles default parameters, priors, mixing-matrix closure, and oscillation-probability closure into an Osc struct ready for use in experiment forward models.

Arguments

  • cfg::OscillationConfig: oscillation configuration (defaults to standard 3-flavour vacuum).

Returns

An Osc instance.

Examples

using Newtrinos

# Default 3-flavour vacuum
physics = Newtrinos.osc.configure()

# With matter effects and inverted ordering
physics = Newtrinos.osc.configure(
    OscillationConfig(flavour=ThreeFlavour(ordering=:IO), interaction=SI())
)

Flavour Models

Newtrinos.osc.FlavourModel — Type
FlavourModel

Abstract type selecting the neutrino mass/flavour model.

Each subtype defines its own set of oscillation parameters (mixing angles, mass splittings, and any BSM quantities) via get_params and get_priors dispatches, as well as a get_matrices method that returns the mixing matrix $U$ and mass-squared eigenvalues.

Standard and BSM subtypes:

  • ThreeFlavour: standard three-neutrino oscillations.
  • ThreeFlavourXYCP: three-flavour with shell parametrization of $\delta_{CP}$.
  • Sterile: 3+1 sterile neutrino model.
  • ADD: Arkani-Hamed–Dimopoulos–Dvali large extra dimensions.
  • Darkdim_Lambda, Darkdim_Masses, Darkdim_cas: dark-dimension model variants.
source
Newtrinos.osc.ThreeFlavour — Type
ThreeFlavour <: FlavourModel

Standard three-flavour neutrino oscillation model.

The PMNS mixing matrix is constructed as $U_{PMNS} = R_{23}(\theta_{23}) \cdot R_{13}(\theta_{13},\, \delta_{CP}) \cdot R_{12}(\theta_{12})$ and the oscillation parameters are:

ParameterDescriptionDefault
θ₁₂Solar mixing angle$\arcsin(\sqrt{0.307})$
θ₁₃Reactor mixing angle$\arcsin(\sqrt{0.021})$
θ₂₃Atmospheric mixing angle$\arcsin(\sqrt{0.57})$
δCPDirac CP-violation phase1.0 rad
Δm²₂₁Solar mass-squared splitting [eV²]$7.53 \times 10^{-5}$
Δm²₃₁Atmospheric mass-squared splitting [eV²]depends on ordering

Fields

  • ordering::Symbol = :NO: neutrino mass ordering. :NO for normal ordering ($\Delta m^2_{31} > 0$), :IO for inverted ordering ($\Delta m^2_{31} < 0$).
source
Newtrinos.osc.ThreeFlavourXYCP — Type
ThreeFlavourXYCP <: FlavourModel

Three-flavour model with a shell (Cartesian) parametrization of $\delta_{CP}$.

Replaces the scalar δCP parameter with a 2-vector δCPshell to avoid discontinuities at the circular boundary $[0, 2\pi)$ during gradient-based fitting.

Fields

  • three_flavour::ThreeFlavour = ThreeFlavour(): underlying three-flavour configuration.

See also ThreeFlavour.

source
Newtrinos.osc.Sterile — Type
Sterile <: FlavourModel

3+1 sterile neutrino model extending the standard three flavours.

Adds a fourth mass eigenstate with mass-squared splitting Δm²₄₁ and three new mixing angles θ₁₄, θ₂₄, θ₃₄. The PMNS matrix is extended to 4×4 via

\[U_{4\times4} = R_{34}\, R_{24}\, R_{14} \cdot \begin{pmatrix} U_{PMNS} & 0 \\ 0 & 1 \end{pmatrix}\]

Fields

  • three_flavour::ThreeFlavour = ThreeFlavour(): underlying three-flavour configuration.

See also ThreeFlavour.

source
Newtrinos.osc.ADD — Type
ADD <: FlavourModel

Arkani-Hamed–Dimopoulos–Dvali (ADD) large extra dimensions model.

Introduces a tower of $N_{KK}$ Kaluza-Klein excitations for each active neutrino, yielding a $3(N_{KK}+1) \times 3(N_{KK}+1)$ mass matrix. The Dirac mass matrix is constructed from the PMNS matrix and absolute neutrino masses, with off-diagonal couplings controlled by the extra-dimension compactification radius.

Additional parameters beyond ThreeFlavour:

ParameterDescriptionDefault
m₀Lightest neutrino mass [eV]0.01
ADD_radiusExtra-dimension compactification radius [μm]0.01

Fields

  • three_flavour::ThreeFlavour = ThreeFlavour(): underlying three-flavour configuration.
  • N_KK::Int = 5: number of Kaluza-Klein modes to include.

See also Cut for excluding heavy KK states from coherent oscillation.

source

Interaction Models

Newtrinos.osc.InteractionModel — Type
InteractionModel

Abstract type selecting the neutrino-matter interaction model used when propagating through Earth layers. Subtypes:

  • Vacuum: no matter effects.
  • SI: Standard Interactions (MSW effect).
  • NSI: Non-Standard Interactions.
source
Newtrinos.osc.Vacuum — Type
Vacuum <: InteractionModel

Vacuum oscillations — no matter effects. Layer densities in Layer are ignored; the baseline is the sum of Path segment lengths.

source
Newtrinos.osc.SI — Type
SI <: InteractionModel

Standard Interactions — coherent forward scattering in matter (the MSW effect).

Adds the Wolfenstein charged-current potential $V_{CC} = \sqrt{2}\, G_F\, N_e$ to the $(\nu_e, \nu_e)$ element and a neutral-current potential to all diagonal elements of the effective Hamiltonian. The sign is flipped for antineutrinos.

source
Newtrinos.osc.NSI — Type
NSI <: InteractionModel

Non-Standard Interactions in matter. Extends the matter Hamiltonian beyond the Standard Model Wolfenstein potential.

source

Propagation Models

Newtrinos.osc.PropagationModel — Type
PropagationModel

Abstract type governing how neutrino quantum states evolve along the baseline.

Subtypes select different physical approximations for the oscillation amplitude:

  • Basic: standard coherent quantum-mechanical propagation.
  • Decoherent: density-matrix evolution with off-diagonal damping.
  • Damping: amplitude-level low-pass filter with incoherent recovery.
source
Newtrinos.osc.Basic — Type
Basic <: PropagationModel

Standard coherent quantum-mechanical propagation (no decoherence effects).

The oscillation amplitude is computed as

\[A_{\alpha\beta} = \bigl(U \, \mathrm{diag}\bigl(e^{-i\,\Delta m^2_j\, L \,/\, 4E}\bigr) \, U^\dagger\bigr)_{\alpha\beta}\]

and the transition probability is $P_{\alpha\beta} = |A_{\alpha\beta}|^2$.

source
Newtrinos.osc.Decoherent — Type
Decoherent <: PropagationModel

Propagation with energy-dependent decoherence via density-matrix evolution.

Off-diagonal elements of the density matrix in the mass eigenbasis are damped by

\[D_{ij} = \exp\!\bigl(-2\,|\Delta\phi_{ij}|\,\sigma_e^2\bigr), \qquad \Delta\phi_{ij} = \frac{\Delta m^2_{ij}\, L}{4E}\]

after coherent phase evolution at each layer crossing.

Fields

  • σₑ::Float64 = 0.1: decoherence strength parameter (dimensionless).
source
Newtrinos.osc.Damping — Type
Damping <: PropagationModel

Propagation with a low-pass filter that damps fast-oscillating amplitudes.

Each mass-eigenstate phase factor is multiplied by a decay $d_j = \exp(-2\,|\phi_j|\,\sigma_e^2)$ and the probability is corrected by an incoherent recovery term $|U|^2 \, \mathrm{diag}(1-d_j^2) \, |U|^{2\,\prime}$.

Fields

  • σₑ::Float64 = 0.1: damping strength parameter (dimensionless).
source

State Selection

Newtrinos.osc.StateSelector — Type
StateSelector

Abstract type controlling which mass eigenstates contribute to the coherent oscillation calculation. Subtypes:

  • All: include every eigenstate (default).
  • Cut: exclude eigenstates above a mass-squared cutoff.
source
Newtrinos.osc.All — Type
All <: StateSelector

Include all mass eigenstates in the oscillation calculation. This is the default.

source
Newtrinos.osc.Cut — Type
Cut <: StateSelector

Exclude mass eigenstates whose $\sqrt{|m^2_j|}$ exceeds a cutoff threshold.

States above the cutoff are averaged incoherently, which is useful for ADD or dark-dimension models where heavy Kaluza-Klein states oscillate too rapidly to be resolved experimentally.

Fields

  • cutoff::Float64 = Inf: mass eigenvalue cutoff [eV]. Default Inf keeps all states.
source

Eigendecomposition

Newtrinos.osc.EigenMethod — Type
EigenMethod

Abstract type selecting the eigendecomposition algorithm for the effective matter Hamiltonian. Subtypes:

  • DefaultEigen: Julia's built-in LinearAlgebra.eigen.
  • BargerEigen (defined in barger_eigen.jl): fast analytic 3×3 decomposition.
source
Newtrinos.osc.DefaultEigen — Type
DefaultEigen <: EigenMethod

Use Julia's built-in LinearAlgebra.eigen for Hermitian matrix diagonalization.

source
Newtrinos.osc.decompose — Function
decompose(H::Hermitian, method::EigenMethod) -> Eigen

Eigendecompose the Hermitian Hamiltonian H using the selected EigenMethod.

This is the extension point for custom eigensolvers. To add a new method, define a subtype of EigenMethod and a corresponding decompose dispatch.

Arguments

  • H::Hermitian: effective Hamiltonian matrix (mass-squared basis or matter-modified).
  • method::EigenMethod: algorithm selector.

Returns

An Eigen factorization with fields vectors and values.

source
Newtrinos.BargerEigen — Type
BargerEigen <: Newtrinos.osc.EigenMethod

Analytic 3×3 Hermitian eigendecomposition using closed-form expressions. Uses the method of Deledalle et al. 2017, which computes eigenvalues via the cubic formula and eigenvectors via closed-form expressions.

Only valid for 3×3 Hermitian matrices (i.e. three-flavour oscillations). Falls back to Julia's eigen for non-3×3 matrices.

source

ftype

Newtrinos.osc.Layer — Type
Layer{T}

A spherical shell of matter with uniform proton and neutron number densities.

Used to represent concentric layers of the Earth in the PREM density model (see EarthLayers in earth_layers.jl). A neutrino trajectory through the Earth is described by a sequence of Path segments, each referencing one layer.

Fields

  • radius::T: outer radius of the shell [km].
  • p_density::T: proton number density [mol/cm$^3$].
  • n_density::T: neutron number density [mol/cm$^3$].
source
Newtrinos.osc.Path — Type
Path

A single segment of a neutrino propagation path through one matter Layer.

A full baseline is represented as a Vector{Path}, one entry per layer traversed. For vacuum oscillations the total baseline is simply sum(segment.length for segment in path).

Fields

  • length::Float64: segment length [km].
  • layer_idx::Int: index into the corresponding StructVector{Layer}.

Core Functions

Newtrinos.osc.get_osc_prob — Function
get_osc_prob(cfg::OscillationConfig) -> Function

Construct the oscillation probability closure for the given configuration.

The returned function osc_prob has two methods:

Vacuum-style (baselines as distances):

osc_prob(E::AbstractVector, L::AbstractVector, params::NamedTuple; anti=false)

Matter-style (baselines as Earth layer paths):

osc_prob(E::AbstractVector, paths::VectorOfVectors{Path}, layers::StructVector{Layer},
         params::NamedTuple; anti=false)

Arguments

  • E: neutrino energies [GeV].
  • L: baselines [km] (vacuum method).
  • paths: per-baseline layer traversals (matter method), from EarthLayers.
  • layers: Earth density layers (matter method).
  • params::NamedTuple: oscillation parameters (mixing angles, mass splittings, etc.).
  • anti::Bool = false: set true for antineutrinos (conjugates the PMNS matrix).

Returns

Array{T,4} of shape (n_E, n_L, n_flav, n_flav) where entry result[i, j, β, α] gives the transition probability $P(\nu_\alpha \to \nu_\beta)$ at energy E[i] and baseline/path index j.

source
Newtrinos.osc.get_matrices — Function
get_matrices(cfg::FlavourModel, eigen_method::EigenMethod=DefaultEigen()) -> Function

Construct a closure that computes the mixing matrix and mass-squared eigenvalues from oscillation parameters.

The returned function has signature matrices(params::NamedTuple) -> (U, h) where:

  • U is the mixing matrix (unitary).
  • h is a vector of mass-squared eigenvalues [eV²].

For ThreeFlavour, returns SMatrix{3,3} and SVector{3} (zero-allocation). For Sterile, returns 4×4 dense matrices. For ADD and dark-dimension models, returns $3(N_{KK}+1) \times 3(N_{KK}+1)$ dense matrices obtained by diagonalizing the full KK mass matrix via decompose.

The closure is ForwardDiff-compatible: all intermediate computations preserve dual-number types through zero(T) / one(T) patterns and type promotion.

Arguments

  • cfg::FlavourModel: flavour model instance (dispatches to the appropriate method).
  • eigen_method::EigenMethod: eigendecomposition algorithm (only used by models that diagonalize a mass matrix, e.g. ADD).

See also get_PMNS, configure.

source
Newtrinos.osc.get_PMNS — Function
get_PMNS(params) -> SMatrix{3,3}

Construct the $3 \times 3$ PMNS leptonic mixing matrix from oscillation parameters.

The matrix is built as

\[U_{PMNS} = R_{23}(\theta_{23}) \;\cdot\; R_{13}(\theta_{13},\, \delta_{CP}) \;\cdot\; R_{12}(\theta_{12})\]

where each rotation matrix uses zero(T) / one(T) to preserve ForwardDiff.Dual number types for automatic differentiation.

Arguments

  • params::NamedTuple: must contain θ₂₃, θ₁₃, θ₁₂, and δCP.

Returns

SMatrix{3,3,Complex{T}} — the PMNS mixing matrix, where T is inferred from the parameter types.

source
Newtrinos.osc.get_abs_masses — Function
get_abs_masses(params) -> (m1, m2, m3)

Compute the absolute neutrino masses from the lightest mass and mass-squared splittings.

For normal ordering ($\Delta m^2_{31} > 0$): $m_1 = m_0$, $m_2 = \sqrt{\Delta m^2_{21} + m_0^2}$, $m_3 = \sqrt{\Delta m^2_{31} + m_0^2}$.

For inverted ordering ($\Delta m^2_{31} < 0$): $m_3 = m_0$, $m_1 = \sqrt{-\Delta m^2_{31} + m_0^2}$, $m_2 = \sqrt{\Delta m^2_{21} - \Delta m^2_{31} + m_0^2}$.

Arguments

  • params::NamedTuple: must contain m₀, Δm²₂₁, and Δm²₃₁.

Returns

A tuple (m1, m2, m3) of absolute neutrino masses [eV].

source

Internal Functions

These functions are not part of the public API but are documented for developers working on the oscillation engine.

Newtrinos.osc.osc_kernel — Function
osc_kernel(U, H, e, l) -> AbstractMatrix

Compute the coherent oscillation amplitude matrix for a single energy and baseline.

Evaluates $A = U \, \mathrm{diag}\!\bigl(e^{-i\, \phi_j}\bigr) \, U^\dagger$ where $\phi_j = \frac{\Delta m^2_j \, L}{4E}$ (in natural units via F_units).

Arguments

  • U::AbstractMatrix{<:Number}: mixing matrix (unitary, $n \times n$).
  • H::AbstractVector{<:Number}: mass-squared eigenvalues [eV²].
  • e::Real: neutrino energy [GeV].
  • l::Real: baseline length [km].

Returns

An $n \times n$ complex amplitude matrix $A_{\beta\alpha}$.

source
osc_kernel(U, H, e, l, σₑ) -> (A, decay)

Compute the oscillation amplitude matrix with low-pass damping.

Same as the coherent osc_kernel but each phase factor is additionally multiplied by a decay $d_j = \exp(-2\,|\phi_j|\,\sigma_e^2)$.

Arguments

  • U::AbstractMatrix{<:Number}: mixing matrix.
  • H::AbstractVector{<:Number}: mass-squared eigenvalues [eV²].
  • e::Real: neutrino energy [GeV].
  • l::Real: baseline length [km].
  • σₑ::Real: damping strength parameter.

Returns

A tuple (A, decay) where A is the damped amplitude matrix and decay is the per-eigenstate decay vector.

source
Newtrinos.osc.compute_matter_matrices — Function
compute_matter_matrices(H_eff, e, layer, anti, interaction::SI, eigen_method=DefaultEigen()) -> (U, h)

Add the MSW matter potential to the effective Hamiltonian and diagonalize.

Modifies H_eff by adding the Wolfenstein charged-current and neutral-current potentials for the given Layer density, then eigendecomposes the result via decompose. Two methods are provided: one for generic AbstractMatrix and an optimized one for SMatrix{3,3}.

Arguments

  • H_eff: effective Hamiltonian in the flavour basis ($U\,\mathrm{diag}(h)\,U^\dagger$).
  • e::Real: neutrino energy [GeV].
  • layer::Layer: matter layer with proton and neutron densities.
  • anti::Bool: true for antineutrinos (flips potential sign).
  • interaction::SI: matter interaction selector.
  • eigen_method::EigenMethod: eigendecomposition algorithm.

Returns

A tuple (U_m, h_m) of matter-modified eigenvectors and eigenvalues.

source
Newtrinos.osc.osc_reduce — Function
osc_reduce(matter_matrices, path, e, propagation) -> Matrix

Combine per-layer oscillation amplitudes along a multi-layer path into a single transition probability matrix for one energy.

Dispatches on PropagationModel:

  • Basic: multiplies amplitude matrices across layers, then takes $|\cdot|^2$.
  • Damping: multiplies damped amplitudes and adds an incoherent recovery term using a path-length-weighted average of $|U|^2$.

Arguments

  • matter_matrices: vector of (U_m, h_m) tuples, one per layer (from compute_matter_matrices).
  • path::Vector{Path}: sequence of path segments for this baseline.
  • e::Real: neutrino energy [GeV].
  • propagation::PropagationModel: propagation model instance.

Returns

An $n \times n$ real matrix of transition probabilities $P_{\beta\alpha}$.

source
Newtrinos.osc.matter_osc_per_e — Function
matter_osc_per_e(H_eff, e, layers, paths, anti, propagation, interaction, eigen_method=DefaultEigen()) -> Array

Compute matter-affected oscillation probabilities at a single energy across all paths.

For each Layer, computes the matter-modified eigensystem via compute_matter_matrices, then reduces along each path via osc_reduce (for Basic/Damping) or via explicit density-matrix evolution (for Decoherent).

Arguments

  • H_eff: effective Hamiltonian in the flavour basis.
  • e::Real: neutrino energy [GeV].
  • layers::StructVector{Layer}: Earth density layers.
  • paths: per-baseline layer traversals (VectorOfVectors{Path}).
  • anti::Bool: true for antineutrinos.
  • propagation::PropagationModel: propagation model.
  • interaction::InteractionModel: matter interaction model.
  • eigen_method::EigenMethod: eigendecomposition algorithm.

Returns

An Array of shape (n_flav, n_flav, n_paths) with $P_{\beta\alpha}$ for each path.

source
Newtrinos.osc.select — Function
select(U, h, cfg::StateSelector) -> (U_sel, h_sel, rest)

Partition mass eigenstates into coherent and incoherent subsets based on the StateSelector strategy.

  • All: returns all states unchanged with rest = 0.0.
  • Cut: states with $\sqrt{|m^2_j|}$ below the cutoff are kept for coherent oscillation; states above it are averaged incoherently and their contribution is returned as the rest matrix.

Arguments

  • U: mixing matrix ($n_{flav} \times n_{states}$).
  • h: mass-squared eigenvalues vector.
  • cfg::StateSelector: selection strategy.

Returns

A tuple (U_sel, h_sel, rest) where:

  • U_sel: mixing matrix columns for coherent states.
  • h_sel: eigenvalues for coherent states.
  • rest: incoherent probability correction matrix (scalar 0.0 or $n \times n$ matrix).
source
Newtrinos.osc.propagate — Function
propagate(U, h, E, L, propagation) -> Array{T,4}
propagate(U, h, E, paths, layers, propagation, interaction, anti, ...) -> Array{T,4}

Compute oscillation probabilities over grids of energy and baseline/path.

Vacuum methods (dispatched by baseline vector L): Loops over all (E, L) pairs, evaluating osc_kernel and squaring amplitudes. Dispatches on PropagationModel for Basic, Damping, and Decoherent propagation.

Matter methods (dispatched by paths::VectorOfVectors{Path}):

  • Vacuum interaction: collapses paths to total lengths and delegates to the vacuum method.
  • SI/NSI: reconstructs the flavour-basis Hamiltonian and calls matter_osc_per_e for each energy.

Arguments

  • U: mixing matrix.
  • h: mass-squared eigenvalues [eV²].
  • E: neutrino energies [GeV].
  • L: baselines [km] (vacuum) or paths/layers (matter).
  • propagation::PropagationModel: propagation model.
  • interaction::InteractionModel: matter interaction model (matter methods only).
  • anti::Bool: true for antineutrinos (matter methods only).

Returns

Array{T,4} of shape (n_flav, n_flav, n_E, n_L) with $P_{\beta\alpha}$ (note: the caller get_osc_prob transposes this to (n_E, n_L, n_flav, n_flav)).
